# Security Policy

## Supported Versions

Flowatch is under active development until v1.0.0; security fixes target the latest release branch.

## Reporting a Vulnerability

**Do not open public issues for security bugs.**
Report privately via  email **sy_alioune@yahoo.fr**.

## Scope

- Application code in this repository
- Build & release workflows

Out of scope: third-party dependencies (report upstream where applicable).

## Disclosure

We prefer coordinated disclosure. After a fix, we credit reporters unless requested otherwise.

# Support

## Before filing

- Check existing issues and docs in `/docs`.

## How to get help

- **Bugs / defects:** open a **🐛 Bug report** issue.
- **How-to / docs gaps:** open a **📚 Documentation** issue.
- **Feature ideas:** open a **✨ Feature request** if you have a well defined feature in mind or **📝  RFC/Proposal** if you are unsure and want to open a discussion.

**Other issues type are internal to the development team**

For security issues, follow **SECURITY.md**.

# FND-SYS-008: Dependency license-compatibility check + NOTICE file + About-modal credits

> **User Story ID**: FND-SYS-008
> **Persona**: SYS
> **Epic**: 5 — Release Pipeline Foundation
> **Milestone**: 0.0.1
> **Source**: `_bmad-output/planning-artifacts/epics.md` (story 5.4)
> **State**: done
> **Labels**: type:user-story, state:done, area:fnd, release:0.0.1


As a maintainer, I want CI to verify every transitive dependency is license-compatible with Apache 2.0, plus a `NOTICE` file at repo root that mirrors into an "About" modal in the app, so that license obligations are visible to operators and enforced on every PR. Per NFR-29, NFR-30.

**Acceptance Criteria:**

**Given** `package.json` lists all production dependencies
**When** `license-checker --production --onlyAllow 'Apache-2.0;MIT;BSD-2-Clause;BSD-3-Clause;ISC;CC0-1.0' --excludePrivatePackages` runs in CI's `check` job
**Then** any disallowed license fails the build with the offending package name
**And** a `NOTICE` file at repo root enumerates each direct dependency + its license + its homepage URL, regenerated by `scripts/release/generate-notice.mjs` (drift between `NOTICE` and `package.json` fails CI)
**And** Flowatch's "About" modal (opened from the Settings gear menu) renders the same NOTICE content (fetched at build time, not at runtime — bundle remains air-gapped per NFR-9)
**And** the About modal shows: app name, version, git SHA (from Story 6.5), Apache 2.0 link, and a scrollable dependency credits list.

# FND-DAA-002: README badges for build, license, and Flowable compatibility

> **User Story ID**: FND-DAA-002
> **Persona**: DAA
> **Epic**: 6 — Distribution & Discovery Foundation
> **Milestone**: 0.0.1
> **Source**: `_bmad-output/planning-artifacts/epics.md` (story 6.4)
> **State**: done
> **Labels**: type:user-story, state:done, area:fnd, release:0.0.1


As Daan (evaluator landing on the GitHub repo), I want the README to display badges for build status, license, and the Flowable version Flowatch is tested against, so that I can assess project health and compatibility in seconds. Per FR-F11.

**Acceptance Criteria:**

**Given** the README has a top-of-file section above the "Quick start"
**When** the maintainer adds shield.io badges for: (a) CI build status (`actions/workflows/ci.yml/badge.svg`), (b) license (`Apache-2.0`), (c) `tested against Flowable 7.2.0` (sourced from `docs/compat.md`'s tested version)
**Then** the three badges render at the top of the README in a single row
**And** the Flowable-version badge value is generated by `scripts/release/update-readme-badges.mjs` from `docs/compat.md` (single source of truth — no hard-coded duplication)
**And** the script is wired into the `check` job of `.github/workflows/ci.yml` so a drift between the README badge and `compat.md` fails CI.

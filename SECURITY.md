# Security Policy

## Supported Versions

Flowatch is under active beta development until v1.0.0; security fixes target the latest release branch.

## Reporting a Vulnerability

**Do not open public issues for security bugs.**

Report privately via  [Github private vulnerability disclosure feature](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/privately-reporting-a-security-vulnerability)

Maintainers aim to acknowledge reports within 14 days and ship a fix or mitigation within 90 days.

## Scope

- Application code in this repository
- Build & release workflows

Out of scope: third-party dependencies (report upstream where applicable).

## Disclosure

We prefer coordinated disclosure. After a fix, we credit reporters unless requested otherwise.
